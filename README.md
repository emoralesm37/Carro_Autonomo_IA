# Carro_Autonomo_IA
Es el desarrollo de un carro robot autónomo capaz de desplazarse y evitar obstáculos utilizando una Raspberry Pi Pico 3 como unidad principal de control. Para lograr este funcionamiento, el sistema integra motores DC, un módulo L298N, un sensor ultrasónico HC-SR04 y un servomotor que permite medir distancias en diferentes direcciones.
